Setup

How the work was organized

One main agent

Claude Opus 5.5 in Claude Code acted as the orchestrator. It planned, wrote most of the code, ran every test and made every commit itself, straight to main, one commit per step.

Helpers for side work

Research and clearly scoped builds went to subagents in the background: scout (Haiku) for reading, worker (Sonnet) for mechanical builds, and general agents (Opus) for research. At most three ran at once, and never two on the same files.

No questions after the start

After one question round the agent decided on its own. Each decision went into a decision log with the reason, and anything only the owner can do went into a checklist.

Done means verified

Nothing counted as done without a check: unit and end-to-end tests, CI on macOS, Windows and Linux, the Android emulator, headless browsers, real releases from CI.

Problems

What broke, and how it was fixed

Most of the time went into things that only show up on real machines and real CI runners.

Windows terminals hung

ConPTY asks for the cursor position before it shows anything, and it ignored an answer that came in two parts.

Answer in one write, and repeat until output moves on.

"The app is damaged"

The first macOS release was only signed by the linker, so a downloaded copy looked broken to macOS.

Sign the whole bundle, plus a Terminal installer without the security prompt.

Passkeys in the admin area

A second factor that got in the way more than it helped for a one-person admin team.

Removed; admin access is an allow-listed account.

A silent updater

The update test installed nothing and logged nothing.

An app log file, which showed the updater refuses linked folders.

Long CI host names

Cloud runners have names over 64 characters, too long for a device name.

A short host name for the relay.

Lost native libraries

CI's cache restore dropped the speech engine's compiled libraries.

Rebuild them after the restore.

Double messages in swarms

Some messages between team members arrived twice.

Deliver each message exactly once.

Pre-releases as "latest"

A test version could have shown up on the public download page.

Public links and updates use stable versions only.
