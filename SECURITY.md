# Security

Please do **not** open a public issue for a security problem.

Report it privately instead: on GitHub, open the **Security** tab of this repository and choose
**Report a vulnerability**. Describe what you found and how to reproduce it. You will get an
answer as soon as possible, and a fix is released through the normal in-app update.

In scope: the desktop app and its background service (`neuralagentd`), the relay at
`agent.neuralhub.dev`, the web remote and the Android app, including the end-to-end encryption
between phone and computer.
