# NeuralAgent brand concepts

Each concept has a monochrome template mark (`concept-x.svg`, viewBox 0 0 64 64, `currentColor`) and a 1024 app icon (`concept-x-icon.svg`: superellipse tile, near-black `#080909` ground with a faint top light, mark in bright `#eef1ee` or ice `#b9d3ff`). Preview: `concepts.png` (1024 / 32 / 16 px).

## A - Agent node
A solid core with three satellites on short spokes. The core is the orchestrator "Neural", the satellites are agents. Bright ink on dark. Few heavy shapes, so it holds up small, but it is close to generic "network/molecule" icons.

## B - Prompt + spark
A terminal chevron `>`, a prompt underscore and a four-point spark in ice. Terminal plus AI in one glance. Chevron and spark are separate shapes, so at 16 px the spark turns to a speck. Needs a simplified 16 px variant (drop the underscore).

## C - Split-pane N
An "N" made of two tall panes and a stepped diagonal of three panes. It reads as a letter and as a terminal grid, which is the product's core idea. Bright ink on dark.

## Recommendation: C
- Legibility at 16 px: large rectangles with 2 px gaps stay legible as a block "N"; A is also solid but B degrades.
- Uniqueness: a pane-built N points straight at the multi-terminal grid; A and B are common motifs.
- Style fit: orthogonal, quiet, continuous-radius rects match the dark, calm NeuralHub look. It works as a macOS template (single colour, no gradients). Suggest tinting one pane with ice as the accent in the colour icon.

## Web icon pipeline (favicons, PWA, Open Graph, Discord)
One script renders every web asset from the master geometry (the C mark of `neuralagent-icon.svg`, superellipse n = 5, ground `#080909` → `#1c1f1e`, ink `#eef1ee`, ice pane `#b9d3ff`):

```sh
# once: a playwright-core with Chromium (any checkout works), plus optional optimisers
npm i --prefix /tmp/pw playwright-core && npx --prefix /tmp/pw playwright install chromium
brew install pngquant oxipng
# from the repo root
PW=/tmp/pw/node_modules/playwright-core/index.mjs node docs/brand/build-web-icons.mjs
```

Output in `apps/web/public/`:
- `favicon.svg` (full-bleed tile, reads on light and dark tab bars), `favicon.ico` (16/32/48, PNG entries), `favicon-32.png`
- `apple-touch-icon.png` 180, opaque (iOS rounds it); `logo.png` 512 tile (notifications, legacy links)
- `app/icon-192.png`, `app/icon-512.png` (purpose any, tile with transparent corners), `app/icon-maskable-512.png` (full bleed, mark inside the 40 % safe circle)
- `og.png` + `og/{download,app,changelog}.png` 1200×630 from `og-template.html` (DM Sans + IBM Plex Mono embedded from node_modules). Card copy lives in `CARDS` in the script.
- `discord/logo-512.png` (Rich Presence large image, opaque, Discord rounds it) and `discord/small-{working,waiting,idle}.png` (128 round status badges: blue play, amber "!", grey moon).

`<head>` conventions (every `apps/web/**/index.html` + `404.html`): `favicon.ico` (sizes 32x32) + `favicon.svg` + `apple-touch-icon.png`, og/twitter tags with the page's card, canonical URL. The first `theme-color` is the ice accent `#b9d3ff` with `id="embed-color"`; Discord uses it for the embed bar, and an inline script removes it so browsers use the dark value after it. `/app/` also links `app/manifest.webmanifest`, uses `black-translucent` on iOS, and a `theme-color` pair (dark/light media) of `#131a3d`, the measured average of the aurora along the top edge.

Desktop (`apps/desktop/src-tauri/icons`) and Android launcher icons (`ic_launcher_mark.xml` vector + PNG mipmaps) already match the master; they are not generated by this script.
